# みなとみらい連続殺人事件

コマンド選択式のテキスト推理アドベンチャーゲームです。ブラウザだけで遊べる単一の HTML ファイル（`index.html`）で、外部ファイルや通信は使いません。

**プレイ:** https://tg2032.github.io/minato-mystery/

## 遊び方

- 画面下のコマンド（調べる／話す／移動する／持ち物／手帳／指名する）を選び、続けて対象を選びます。数字キー 1〜9 でも選べます。
- 手がかりを集めて「手帳」に記録し、証拠が揃ったら「指名する」で犯人を告発します。
- 行き詰まったら、相棒アキラに「アドバイスをもらう」と方針を教えてくれます。
- 誤った人物の指名は2回まで許されます。3回目で、その人物のバッドエンドになります。
- 真相に至る証拠は複数あり、手がかり6種のうち3つ以上で真エンドに届きます（ルートは一つではありません）。
- 進行状況はブラウザの localStorage に自動保存されます。
- ヘッダーの「♪」でアンビエント音と効果音を切り替えられます（初期はオフ）。

## 注意

- 登場する人物・団体・事件はすべてフィクションです。実在の人物・団体とは関係ありません。
- 舞台は横浜のみなとみらい地区ですが、物語上の施設・会社は架空のものです。

## 画像について

キャラクターと背景の画像はすべて AI で生成したもので、`index.html` に JPEG（base64）として埋め込んでいます。

- 生成環境: ComfyUI（ローカル）、チェックポイント `majicmixRealistic_v6`、アップスケールに RealESRGAN x4plus
